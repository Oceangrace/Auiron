# Issues and suggestions

**English** / [Русский](CONTRIBUTING.ru.md) · [Aurion](README.md)

If Aurion or the example Cleric HUD is not working correctly, report it in Issues.
You do not need to know whether the cause is the app, game data, or the profile: describe what you see.

## Before opening an issue

- Search existing issues. If the same problem is already reported, add your details there.
- Keep one problem or suggestion per issue so it can be discussed and tracked separately.
- Use a specific title, such as “Party frames disappear after entering a second dungeon”.
- Write in English or Russian. Open **Issues → New issue** and choose the matching form.

## Reporting a bug

Include your Aurion version, what happened, what you expected, and the steps that led to it.
If it only happens sometimes, say so; an imperfect report is still useful.

For HUD problems, mention whether you use the example Cleric profile, a modified copy,
or another interface. Include your class and skill name when relevant. For layout issues,
add your screen resolution and HUD scale. Mention if the problem followed a restart,
teleport, or party change, and whether the editor or simulator was open.

Screenshots, short videos, and exact error messages help. An exported profile or a relevant
excerpt from `%APPDATA%/aurion/aurion.log` can also be useful, but attachments are optional.
Issues are public: remove personal information from attachments and share packet captures
only if requested and after checking their contents.

## Suggesting a feature

Explain the problem you want to solve and how the proposed feature would help.
A sketch, example, or current workaround can make the suggestion easier to discuss.
